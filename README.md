# واژه‌یاب مستندات پایتون

**واژه‌یاب مستندات پایتون** ابزاری است برای جست‌وجوی معادل فارسی واژگان تخصصی انگلیسی به‌کار رفته در مستندات پایتون. این ابزار بخشی از پروژه‌ی [مستندات فارسی پایتون](https://github.com/python/python-docs-fa) است و هدف آن تسهیل‌سازی پیدا کردن ترجمه‌ی مناسب برای کلمات تخصصی استفاده شده در مستندات است.

## امکانات

- **جست‌وجوی واژه‌ی انگلیسی** و نمایش معادل فارسی ثبت‌شده‌ی آن در واژه‌نامه‌ی رسمی پروژه.
- **فهرست موقعیت‌های تکرار واژه** در متن مستندات، به همراه ترجمه‌ی فارسی هر بخش، تا بتوانید کاربرد واژه را در بافت (context) واقعی ببینید.

## دسترسی به سایت

ابزار به‌صورت آنلاین و رایگان در آدرس زیر در دسترس است:

<https://sepehr-rs.github.io/python-docs-fa-glossary/>

## اجرای پروژه به‌صورت محلی

در صورتی که مایل باشید پروژه را روی سیستم خود اجرا کنید:

1. مخزن پروژه را کلون کنید:
   ```bash
   git clone https://github.com/sepehr-rs/python-docs-fa-glossary.git
   cd python-docs-fa-glossary
   ```
2. اسکریپت اجرا را فعال کنید:
   ```bash
   ./deploy.sh
   ```
3. پس از اجرای موفق اسکریپت، آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر خود باز کنید.

> **نکته:** پیش از اجرا مطمئن شوید ابزارهای مورد نیاز (مانند `bash` و `python`) روی سیستم شما نصب هستند.

## گزارش اشکال یا ارائه‌ی پیشنهاد

مشارکت شما به بهبود این ابزار کمک می‌کند. برای گزارش اشکالات، درخواست ویژگی‌های جدید، یا هر نوع پیشنهاد دیگر، لطفاً از بخش [Issues](https://github.com/sepehr-rs/python-docs-fa-glossary/issues) مخزن پروژه استفاده کنید. پیش از ثبت issue جدید، بهتر است ابتدا issue های موجود را بررسی کنید تا از تکراری نبودن گزارش مطمئن شوید.
